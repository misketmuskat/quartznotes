### Komparativ
- **wie:** A = B — gleich
	- Das Wetter in DA ist **(genau)so** kalt **wie** in meiner Heimat.
- **als:** A /= B — underschiedlich
	- Das Wetter in DA ist **kälter als** in meiner Heimat.

| Grundform | Komparativ    | Superlativ         |
| --------- | ------------- | ------------------ |
| schön     | schön**er**   | am schön**sten**   |
| viel      | **mehr**      | am **meisten**     |
| gut       | **besser**    | am **besten**      |
| bequeem   | bequeem**er** | am bequeem**sten** |
| hoch      | **höher**     | am **höchsten**    |
|           |               |                    |
- Der Berg ist hoch.
	- Der **hohe** Berg. (This is not the same with höher)
	- Der **höhere** Berg.
	- Der **höhste** Berg.

### Komposita

| Komposita                           |                                          |     |
| ----------------------------------- | ---------------------------------------- | --- |
| **das** Wahl \| **modul**           | Modul, das ich wählen kann               |     |
| **der** Studien \| **beginn**       | Beginn des Studiums                      |     |
| **die** Auf \| nahme \| **prüfung** | eine Prüfung für die Aufnahme an der Uni |     |
* **Nomen + Nomen**
* **Verb + Nomen**
	* lesen + Brille = die Lesebrille
* **Adjektiv + Nomen**
	* klein + Staat = der Kleinstaat
* **Präposition + Nomen**
	* unter + Geschoss = das Untergeschloss = der Keller
