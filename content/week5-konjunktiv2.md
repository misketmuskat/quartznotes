## Konjunktiv II
- **For what can we use it?**
	- Wunsch
	- Vorschlage
	- Hofflichkeit
	- Ratschlag - "sollten"
	- irreale Bedingung
- **Kondition - Bedingung**
	- Wenn . . ., dann . . .
		- Präsens, Perfekt, Präteritum > real
		- Konjunktiv II > irreale
- Wenn ich eine Million **bekäme**, dann **würde** ich ein Haus **kaufen**.

| Präsens | Präteritum | Konjuktiv II       |
| ------- | ---------- | ------------------ |
|         | -te        | würden + Infinitiv |
| haben   | hatte      | hätte              |
| sein    | war        | wäre               |
| können  | konnte     | könnte             |
| dürfen  | durfte     | dürfte             |
| müssen  | musste     | müsste             |
| wollen  | wollte     | w                  |
| wissen  | wusste     | wüsste             |
| gehen   | ging       | ginge              |

| **NS mit wenn**                          | **Hauptsatz**                                    |
| ---------------------------------------- | ------------------------------------------------ |
| *Wenn* du uns Bescheid geben *könntest*, | *wäre* das toll.                                 |
| *Wenn* es bis Dienstag nicht da *ist*,   | *frage* ich nochmal nach.                        |
| **NS ohne wenn**                         | **Hauptsatz**                                    |
| *Wäre* das Päckschein noch in DH,        | *käme* es in 8 Tagen an.                         |
| **Hauptsatz**                            | **NS mit wenn**                                  |
| Ich *fände* es schön,                    | *wenn* wir alle zusammen Urlaub machen *würden*. |
| Ich *würde* den Status abfragen,         | *wenn* ich die Nummer *wüsste*.                  |
